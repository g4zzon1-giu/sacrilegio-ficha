Sincronização Online (Grátis)

Por padrão, suas fichas já ficam salvas neste aparelho. Para que todos os jogadores no celular sincronizem ao vivo com o seu Escudo do Mestre via GitHub Pages:

  1. Acesse console.firebase.google.com e crie um projeto gratuito.
  2. No menu lateral, crie um Realtime Database (iniciar em Modo de Teste).
  3. Copie a URL do banco (ex: https://sua-mesa-default-rtdb.firebaseio.com) e cole abaixo.
  4. Compartilhe o link do site (ou este arquivo com a URL já salva) com os jogadores!
